Quick Setup

How to Install.

Follow these quick 3-step instructions to get Velvet Music running on your device in seconds.

1

Download the Velvet Music APK

Tap the "Download Velvet-Music.apk" button above. The ~12.4 MB installation package will begin downloading immediately to your device.

2

Allow "Install Unknown Apps" If Prompted

If your browser shows a safety warning ("File might be harmful"), tap "Download anyway". Open the file; if Android asks for permission, tap Settings → Allow from this source.

3

Tap Install and Enjoy Studio Sound

Tap "Install". Once installed, grant music storage permission to automatically scan and index your offline tracks with album art!

1

Download the Windows Zip Package

Click the "Download Windows Package (.zip)" button above to download the ultra-compact portable distribution file.

2

Extract the Zip File

Right-click Velvet-Music-Windows-Portable.zip and select "Extract All..." to any folder (e.g. Desktop or Documents).

3

Double-Click "Launch-Velvet-Music.bat"

Double-click the launcher script. Velvet Music will open immediately in a standalone, borderless native studio app window with full keyboard shortcuts!
